# Tic Tac Toe XO 🎮

لعبة إكس أو (Tic Tac Toe) تفاعلية وبسيطة، مبنية باستخدام HTML, CSS, و JavaScript.

## ✨ المميزات
- 🤖 اللعب ضد الذكاء الاصطناعي (Play with AI)
- 👥 اللعب مع صديق على نفس الجهاز (With Friend)
- 📊 عداد نتائج لكل لاعب (You, Draw, AI)
- 🔄 زر لإعادة اللعبة (Play Again)
- 🎨 تصميم بسيط وأنيق

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript

## 🚀 طريقة التشغيل
1. حمّلي المشروع أو اعملي clone له
2. افتحي ملف index.html مباشرة بالمتصفح
3. استمتعي باللعب!
